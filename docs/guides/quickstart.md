# Guide de Démarrage Rapide (Tutoriel)

Bienvenue dans le guide de prise en main de **CleanYourTV Desktop Manager**. En moins de 5 minutes, votre téléviseur sera débarrassé de ses publicités et son interface redeviendra fluide.

---

## Étape 1 : Activer le Débogage sur la Télévision

1. Allumez votre télévision avec sa télécommande physique.
2. Allez dans **Paramètres** (`⚙️`) → **Préférences relatives à l'appareil** (ou **Système**) → **À propos**.
3. Descendez jusqu'à la ligne **Numéro de build** (ou **Build de l'OS Android TV**).
4. Cliquez **7 fois de suite** sur le bouton central **OK**. Un message confirme que vous êtes développeur.
5. Revenez en arrière et entrez dans le nouveau menu **Options pour les développeurs**.
6. Activez :
   - **Débogage USB**
   - **Débogage réseau** (ou **Débogage sans fil**)
7. Notez l'adresse IP affichée dans **Paramètres** → **Réseau & Internet** (ex: `192.168.1.50`).

---

## Étape 2 : Lancer le Gestionnaire sur votre PC

1. Téléchargez la dernière version portable : [`CleanYourTV-Manager-v1.0.0-windows-x64.zip`](https://github.com/Gnzikoune/CleanYourTV-Desktop/releases/latest).
2. Décompressez l'archive où vous le souhaitez.
3. Double-cliquez sur `CleanYourTV-Manager.exe`.
4. Dans le champ en haut à droite, tapez l'adresse IP de votre TV et cliquez sur **⚡ Connecter**.
5. Regardez votre écran de télévision : cochez **"Toujours autoriser depuis cet ordinateur"** et validez sur **OK**.

---

## Étape 3 : Nettoyer & Accélérer en 3 Clics

1. **Accélération des Animations :**
   - Rendez-vous dans l'onglet **Boost & Sécurité Système**.
   - Cliquez sur **Appliquer 0.5x**. L'interface de votre TV devient immédiatement 2 fois plus réactive.
2. **Blocage des Publicités Système :**
   - Cliquez sur **Activer AdGuard**. Les traqueurs et pubs sont bloqués sur toutes les applications de la TV.
3. **Optimisation Machine AOT :**
   - Cliquez sur **Compiler AOT**. Le lanceur d'applications est compilé en code machine direct.
4. **Supprimer le Bloatware :**
   - Rendez-vous dans l'onglet **Débloat & Applications**.
   - Désactivez en un clic les bannières publicitaires et modules de démonstration magasin.
